FaceGate

Face ID-style consent interface for Gaze. Approve sudo and polkit elevation with a glance. Your password always works too.

FaceGate in action on KDE Plasma — sudo approved by face glance, with automatic password fallback inside the island.

Install

Requirements: an Arch-based system with Wayland, Gaze 0.2.7 or newer, and a webcam (an IR camera is strongly recommended). KDE Plasma is strongly recommended for the best experience.

AUR (recommended)

yay -S facegate        # or: paru -S facegate
facegate-enable        # once per user, from your Wayland session
facegate-settings      # add your face

The AUR package installs FaceGate, its dependencies (including gaze-bin), and configures PAM and polkit automatically.

Install from AUR View source

Manual install from source

git clone https://github.com/sguergachi/facegate.git
cd facegate
./setup.sh

Run setup as your normal user. It installs dependencies, configures PAM/polkit, and opens FaceGate to add your first face.

What FaceGate does

One thing at a time

Every screen has one job and one primary action. No title bars, borders, toolbars, or visible chrome that isn't doing work.

Consent before camera

The camera never starts without an explicit Approve. Changes need admin approval every time. The password is always a way through.

Physical, not flat

Surfaces behave like objects. Every change is continuous from what's on screen. Nothing jumps. Colour carries meaning, never decoration.

Design system

FaceGate's interface follows Apple's Human Interface Guidelines adapted to KDE Plasma — clarity, deference, depth. Dark-only palette, physical surfaces, and honest security copy. Full specification in DESIGN.md.
